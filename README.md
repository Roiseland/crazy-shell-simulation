# 疯狂的贝壳：采样性能仿真

本项目用 Python 生成采样装置的方案级仿真数据和四联结果图。模型用于展示实验设计、参数敏感性和数据处理流程，当前结果不代表样机实测性能。

## 环境

当前电脑的 Python 3.14 已包含 NumPy、SciPy、pandas 和 Matplotlib。进入本目录后运行：

```bash
python3 main.py
```

结果写入 `outputs/`：

- `trial_results.csv`：每次模拟的原始记录；
- `summary.csv`：四个面板使用的汇总数据；
- `simulation_results.png`：高清位图；
- `simulation_results.pdf`：矢量图。

## 模型结构

模型使用三个层次：

1. 泵送量由单周期扫掠体积、驱动频率、有效采样时长、充液衰减和 2 Hz 附近的响应增益计算；
2. 底质类型影响留样比例、穿透比例及运行失败概率；
3. 每个工况重复 100 次，引入制造、介质和控制波动，统计均值、标准差和变异系数。成功事件使用分层随机抽样，使有限次数下的成功率稳定对应配置概率。

单次能耗包含采样周期内的控制、运动与驱动功耗，使用二次频率模型估算。重复性使用采样量的变异系数：

```text
CV = 标准差 / 均值 × 100%
```

所有假设参数集中在 `config.json`。获得样机数据后，应优先更新：扫掠体积、充液时间常数、底质留样比例、堵塞概率、功率系数和各项随机波动。

## 文件

- `main.py`：命令行入口；
- `simulation.py`：低阶模型、蒙特卡洛试验和汇总；
- `plot_results.py`：四联图生成；
- `config.json`：工况和假设参数；
- `requirements.txt`：依赖说明。

## 结果解释

采样成功定义为：完成本次运行，且有效深度不低于 12 cm、留样量不低于 12 mL。不同场景的设计目标深度只用于图 C 的达标比较。

成功率来自 100 次模拟，因此以 1% 为最小统计步长。若改回每组 10 次，成功率只能以 10% 为步长变化。
